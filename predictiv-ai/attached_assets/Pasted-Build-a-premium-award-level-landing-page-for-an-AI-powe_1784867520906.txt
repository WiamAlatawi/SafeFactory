Build a premium award-level landing page for an AI-powered Predictive Maintenance platform designed for industrial equipment.

IMPORTANT:
Do NOT create a normal SaaS landing page.
Do NOT use generic fade-in animations.
The page should feel alive and react continuously to scrolling.

Reference only the interaction philosophy of websites like Active Theory, Cuberto, and Locomotive Studio, but create an original design.

-----------------------------------
DESIGN STYLE
-----------------------------------

Minimal.
Modern.

Industrial.

Primary colors:
White (#FFFFFF)

Cyan Accent (#38BDF8)

Large spacing.
Clean typography.
No visual clutter.

The interface should look like Apple + Stripe + modern industrial software.

-----------------------------------
SCROLL EXPERIENCE
-----------------------------------

Scrolling should drive the experience.

Never trigger animations only when entering a section.

Instead every element must move continuously according to scroll progress.

Use:

GSAP ScrollTrigger (scrub:true)

or

Framer Motion useScroll()

Everything should interpolate smoothly.

Use Lenis for smooth scrolling.
